# Cineverse – Milestone 1: 3D seat picker

    npm install
    npm run dev      # http://localhost:3000

Click seats, or use "Best N seats". Switch camera: Overview / From stage / Balcony / Bird's eye.
Files: lib/hall.ts (layout + best-seats), lib/store.ts (state), components/SeatPicker.tsx (3D scene + UI).
